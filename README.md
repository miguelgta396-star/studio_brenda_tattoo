## 🚀 Como Ativar o GitHub Pages

1. Crie um repositório no GitHub (ex: `studio-brenda-tattoo`).
2. Faça o upload dos arquivos `index.html`, `style.css` e suas fotos `foto-portfolio-1.jpg` a `foto-portfolio-6.jpg`.
3. No seu repositório do GitHub, vá em **Settings** > **Pages**.
4. Em **Branch**, selecione `main` (ou `master`) e a pasta `/ (root)`.
5. Clique em **Save**. O GitHub fornecerá seu link online em poucos segundos!
